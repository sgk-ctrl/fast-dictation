Local Mac dictation for long thoughts

Speak into your Mac. Keep the audio on your Mac.

Fast Dictate turns short commands and long voice notes into text using local Whisper transcription. No account, no cloud audio, no meeting bot energy.

Copied to Notes The useful part of dictation is not recording. It is getting a messy thought into the place you were already writing.

Built like a utility, not a surveillance room.

Private

Audio is recorded and transcribed locally through `whisper.cpp`. The default path does not need an account or API key.

Long-form

Use quick dictation for a sentence, or 1-minute, 5-minute, and 15-minute presets for voice notes that need room.

Direct

The transcript lands on your clipboard and can paste into the active app, so the tool does not become another inbox.

Run the Mac app.

Build the menu bar app, open it, then pick a duration from the Dictate menu. For the longest test, choose Extended Voice Note 15 Minutes.

cd ~/fast-dictation
scripts/build-app.sh
open "$HOME/Applications/Fast Dictate.app"
